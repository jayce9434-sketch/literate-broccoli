# Melodic Isles: Resonance

An original, free-to-play musical creature collection fangame inspired by the collection, breeding, island-performance, and progression loops of creature-music games. All creatures, names, vector art, UI skin, code, and generated musical parts in this project are original. No My Singing Monsters art, audio, names, or extracted assets are included.

## GitHub Pages
Upload every file from the ZIP directly into the root of one GitHub repository. There are intentionally no folders. Enable Settings > Pages > Deploy from a branch > main > root.

## Included systems
- 5 original islands with distinct visual palettes, tempos, roots, and arrangements
- 55 original species, including one Island Titan per island
- Common, Rare, Epic, and Legendary forms for every species (220 collection slots)
- Two-parent breeding with level-4 breeder requirements, real-time incubation, rarity luck, instant finish, and rarity rerolls
- Real timestamp timers that continue while the game is closed
- Monster feeding to level 20, Castle bed capacity/upgrades, happiness from decoration boosts, and coin production with up to 12 hours of offline accumulation
- Island decoration income boosts, Harmony Boosts, permanent Star mastery, quests, rotating quests, daily reward, levels, XP, collection milestones
- Browser localStorage autosave plus export/import save codes
- Procedural Web Audio songs plus original WAV UI/coin/hatch/quest sound effects with Music/SFX sliders from 0% to 2000%
- Reusable QA button: +3,000 Gems with a 0.1-second cooldown
- iPad/iPhone/mobile and desktop responsive controls
- Installable PWA and service-worker offline cache
- No CDNs, frameworks, external dependencies, or in-game emojis
